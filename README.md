About

Deployed an IT ticketing system that simulated enterprise-level scenarios, answered client inquiries, and troubleshot technical issues using remote 
and Active Directory software tools

I have practiced on several ticketing systems (Zendesk, Spiceworks, and ServiceDesk Simulator) to build experience and knowledge of handling multiple
user tickets while following the full ticket lifecycle. It was crucial to prioritize, categorize, and escalate tickets from last critical to the most.

ServiceDesk Simulator offered a variety of training exercises such as Active Directory group management, password resets or lockouts, communicating 
with simulated (frustrated) users, and creating and solving tickets within a specific deadline.This project allowed me to create a ticket from a 
simulated user, identify the symptoms the user is experiencing, and to resolve issues effectively using basic troubleshooting tools. On ServiceDesk 
Simulator, I documented a ticket that required me to use Active Directory to check a specific user computer that would not power on at all. I confirmed 
that neither of the power outlet or equipment solved the issue, which resulted me deploying a computer using Server imaging. I followed a standard ticket 
procedure to which I assigned a new computer for the user, replacing the device for the current defective computer. The simulation taught me full 
instructions on how to handle Asset Tracking Management,delivering the new PC deployment to the user, and created a new asset ID in our asset inventory for 
the newly delivered computer. 

Similar to ServiceDesk Simulator, Spiceworks Cloud Help Desk offers a training course which allowed me to create a ticket and follow the lifecycle procedure 
to ensure each ticket has been resolved in few response times. Spiceworks' training simulator taught me how to assign tickets, escalate them, and to handle 
internal and public notes for platform communication.  During each step of the ticketing process, I was able to perform the IT Ticket Lifecycle:
  Categorization
  Prioritization
  Routing/ Assignment
  Status Update
