Deployed a Windows Server 2022 and domain controller. Troubleshot and configured using PowerShell bulk scripting, GPO passowrd policies, and NTFS file permissions to simulate user and group policy management 

Using PowerShell scripting, I created a bulk script detailing the process of adding multiple users to their designated OUs simultaneously. Working in an IT, enterprise-level environment requires one to add multiple users or clients at once,  
which the Bulk script provision allows IT professionals to perform this task quickly and efficiently.There were several discrepancies while adjusting the bulk script, some measurements were taken to solve a troubleshooting scenario, and to find a common 
resolution using several tools at my disposal (search engine, Sandbox Testing, Active Directory Knowledge).

After troubleshooting PowerShell scripts, I managed Group Policy Organizations and NTFS file permissions. While studying for the CompTIA Network+, I found that the most effective method of securing and segmenting different resources across multiple departments
is to prioritize the use of RBAC control within any Entra ID infrastructure. This project gave me the opportunity to follow standard compliance procedures while properly configuring user account and identity management. I successfully managed to simulate how
an IT professional could configure a hybrid environment from an on-premises virtual machine to a Microsoft Entra ID portal. I also learned how to manage user accounts and to secure information by implementing least privilege access across all simulated users.

I have learned and developed new knowledge from studying the Network+ (which I am now certified) and from various sources online. Thank you again for taking the time to read this, I will update my new adjustments for my project soon.
